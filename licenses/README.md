## Lucide icons

The curated icon shapes in `bills/icon_catalog.json` come from `lucide-static` 1.72.0, https://www.npmjs.com/package/lucide-static/v/1.72.0, from https://github.com/lucide-icons/lucide. Distributed under the included ISC license (with the upstream Feather notice). Only selected SVG shapes are bundled; there is no runtime CDN or npm dependency. Labels, groupings, and search terms are PayBillz metadata. Existing PayBillz icons are retained.
